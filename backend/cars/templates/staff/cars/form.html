{% extends "staff/base.html" %} {% comment %} Add or edit one car, with its gallery of photos and videos. Photos and videos share one table and one order column because they share one number space in the store -- two tables would suggest two sequences, and there is only one. Only photos get a "card photo" radio: a video can never be the listing card, and that is a property of the item type rather than a rule this page enforces. `direct-upload.js` sends the bytes to S3 before the form submits and writes the storage name into a hidden field next to each file input, which is how a 200 MB walkaround gets past Lambda's ~4.5 MB request ceiling. It picks the size limit from the input's name, so the video formset's `videos-0-video` needs no change to the script. It is progressive enhancement: the file inputs stay ordinary file inputs, so if the script fails the form still works through Django's normal upload path -- for a photo. A video large enough to matter will not fit through it, which is the whole reason the direct path exists. {% endcomment %} {% block content %}
